## 🧠 Featured AI & Data Work

### 🏦 Generative AI SAR Automation
**Agricultural Bank of China — Graduate Practicum**

Built a Generative AI system designed to automate the drafting of **Suspicious Activity Reports (SARs)** for financial crime and AML compliance.

**Tech:** Python • SQL • PostgreSQL • AWS Bedrock • Llama 3.3 • DeepSeek R1 • FAISS • LangChain • Hugging Face • RAG

Key contributions:

- Designed a RAG-based workflow combining structured banking data with unstructured compliance narratives
- Built retrieval pipelines using **FAISS and sentence-transformer embeddings**
- Used **Llama 3.3 70B Instruct and DeepSeek R1 through AWS Bedrock**
- Developed section-level prompting and structured fact-extraction workflows to reduce hallucination
- Designed evaluation frameworks to measure factual accuracy and narrative completeness
- Reduced estimated SAR drafting time by **86%**
- Identified approximately **$22K in projected annual efficiency savings**
